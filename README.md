## 🧩 O que uma ficha possui?

**Título → descrição didática → URL completa → finalidade → como começar → dica/truque → modalidade de acesso → freemium → uso comercial → status de verificação.**

O arquivo [FONTES/catalogo.json](FONTES/catalogo.json) permite construir sistemas de busca e a versão [CSV](FONTES/catalogo.csv) pode ser importada no Google Planilhas. Considere estes registros uma **curadoria em evolução**, não certificação de disponibilidade, autoria, segurança, preços ou licenças.

## ⚙️ Exemplo de fluxo seguro

**Modelar → revisar topologia → abrir UV → atribuir materiais PBR → fazer bake → rigar/animar → otimizar geometria e texturas → exportar GLB/glTF → validar no destino → registrar evidências de licença e performance.**

## 🛡️ Mission Lock SIN

- Português brasileiro claro, termos técnicos definidos na primeira ocorrência; iniciante e especialista devem conseguir usar.
- Nunca duplicar URLs na base; atualização aditiva, versionada e rastreável.
- Nenhum link promove aprovação automática de uso comercial, redistribuição, marca, imagem ou IA.
- Não executar plugins externos sem inspeção, nem redistribuir assets de terceiros sem permissão.
- Informação documentada ≠ integração testada ≠ homologada em produção.
- Padrões e documentação primária têm prioridade; atualizações de preços e políticas exigem reconfirmação.
- O escopo é **3D completo e interdisciplinar**: games, web, VFX, cinema, arquitetura, ciência, indústria, XR e impressão 3D.
