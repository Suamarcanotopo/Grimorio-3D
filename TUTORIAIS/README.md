# Laboratório de aprendizagem — 37 projetos guiados

O objetivo é ensinar a concluir tarefas verificáveis. **Não é uma coleção de links soltos**: cada projeto tem pré-requisitos, passos, resultado, erros, dependências e referência de boas práticas.

## Antes dos tutoriais completos

Use os [dez experimentos HTML offline](../EXEMPLOS/README.md) para compreender ideias de 3D sem depender de engine ou headset. Depois prossiga para o roteiro e software específico.

## Como usar

1. Leia o [glossário](../GLOSSARIO/README.md) dos termos desconhecidos.
2. Escolha projeto do seu nível e faça **uma etapa por vez**.
3. Salve arquivo nativo, exportação e captura de resultado.
4. Siga a dependência específica para destino, sem presumir integração universal.
5. Verifique direitos, desempenho e disponibilidade da plataforma antes da publicação.
