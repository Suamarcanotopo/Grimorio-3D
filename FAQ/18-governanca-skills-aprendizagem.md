## 1. Como sei se uma fonte 3D está realmente atualizada?

**Resposta:** Confira data, versão e documentação da organização responsável, não somente o título do blog.

**Por que isso importa?** Uma API antiga pode ter sido removida ou modificada.

**Como fazer:**

1. Abra docs oficiais.
2. Identifique release.
3. Registre consulta.
4. Teste exemplo.

**Onde aprender / boas práticas:** https://github.com/Suamarcanotopo/grimorio-skills
